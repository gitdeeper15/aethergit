## Purpose

This directory contains the literature review for AetherGit. The review positions AetherGit against four comparator systems and the broader distributed-systems literature.

---

## Comparator Systems

| System | Source | Role |
|---|---|---|
| **Git** | Chacon & Straub (2014) | Baseline distributed VCS |
| **Piper** | Potvin & Levenberg (2016) | Centralized monorepo VCS |
| **Sapling/Mononoke** | Meta Platforms | Scalable monorepo VCS |
| **Scion** | Anthropic (2026) | Agentic source control case study |

---

## Five Traditions to Examine

1. **Distributed version control** — Git, Mercurial, Darcs.
2. **Centralized monorepo systems** — Piper, Sapling/Mononoke.
3. **Content-addressed storage** — IPFS, Git objects, Nix.
4. **Distributed databases** — Spanner, CockroachDB.
5. **Agentic software engineering** — Scion, autonomous code generation.
